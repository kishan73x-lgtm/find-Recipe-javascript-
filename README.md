# Recipe Finder App 🍽️

A responsive Recipe Finder application built using HTML, CSS, and JavaScript.
Users can search for recipes and view details using a public recipe API.

## 🚀 Features
- Search recipes by name
- Display recipe results dynamically
- View recipe details
- Responsive design
- Clean and simple UI

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript
- Fetch API / Axios
- MealDB API
